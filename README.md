# 足球人生模擬器 ⚽

純文字的足球生涯養成遊戲，架構沿用《野球人生模擬器》。從 15 歲青訓開始，經歷簽約、旅外、國家隊，直到引退。

▶ **線上試玩：** <https://footlife-eta.vercel.app>（Vercel）｜<https://antykx.github.io/footlife/>（GitHub Pages）

目前版本：**v0.13.0**（M0～M8 完成，持續擴充劇情、事件與平衡）。
